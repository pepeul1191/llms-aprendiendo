\section{Introducción}
Este documento establece los procedimientos, intervalos y especificaciones técnicas para el mantenimiento preventivo y correctivo de un motor diésel de camión. Su objetivo es garantizar la confiabilidad, seguridad y vida útil del equipo.

\textbf{Nota:} Los valores entre corchetes \texttt{[ ]} deben ser sustituidos por los datos específicos del fabricante o del vehículo.

\section{Seguridad}
Antes de realizar cualquier intervención, observe las siguientes medidas:
\begin{itemize}
    \item Detenga el motor y espere a que se enfríe.
    \item Desconecte el terminal negativo de la batería.
    \item Use equipo de protección personal: guantes, gafas, calzado de seguridad.
    \item No trabaje bajo un vehículo sostenido solo por el gato hidráulico.
    \item Evite el contacto con aceite, combustible y refrigerante calientes.
    \item Disponga los residuos según la normativa ambiental local.
\end{itemize}

\begin{quote}
\textbf{Advertencia:} El sistema de inyección diésel trabaja a alta presión. No desconecte tuberías con el motor en marcha.
\end{quote}

\section{Procedimientos de mantenimiento}

\subsection{Cambio de aceite y filtro}
\begin{enumerate}[label=\arabic*.]
    \item Calentar el motor a temperatura normal y detenerlo.
    \item Colocar un recipiente bajo el tapón de drenaje.
    \item Retirar el tapón y drenar el aceite completamente.
    \item Reemplazar el filtro de aceite y lubricar la junta.
    \item Colocar el tapón con arandela nueva. Par: [ ] N·m.
    \item Rellenar con aceite nuevo hasta el nivel correcto.
    \item Arrancar el motor, verificar fugas y presión de aceite.
    \item Apagar, esperar y verificar nuevamente el nivel.
\end{enumerate}

\subsection{Cambio de filtros de combustible}
\begin{enumerate}[label=\arabic*.]
    \item Limpiar la zona alrededor del filtro.
    \item Retirar el filtro usado y desecharlo.
    \item Llenar el filtro nuevo con combustible limpio.
    \item Lubricar la junta y montar el filtro. Par: [ ] N·m.
    \item Purgar el sistema con la bomba manual.
    \item Arrancar el motor y verificar fugas.
\end{enumerate}

\subsection{Revisión del sistema de refrigeración}
\begin{enumerate}[label=\arabic*.]
    \item Verificar nivel y estado del refrigerante.
    \item Revisar mangueras, abrazaderas y radiador.
    \item Comprobar funcionamiento del termostato.
    \item Medir punto de congelación con refractómetro.
    \item Cambiar refrigerante según intervalo.
\end{enumerate}

\subsection{Ajuste de válvulas}
\begin{enumerate}[label=\arabic*.]
    \item Motor frío y desconectado.
    \item Retirar tapa de balancines.
    \item Girar el cigüeñal hasta la marca de PMS.
    \item Ajustar válvulas según orden de encendido.
    \item Admisión: [ ] mm. Escape: [ ] mm.
    \item Revisar y montar tapa con junta nueva.
\end{enumerate}

\subsection{Revisión de inyectores}
\begin{enumerate}[label=\arabic*.]
    \item Limpiar la zona de inyectores.
    \item Retirar inyectores y enviar a banco de pruebas.
    \item Verificar caudal, pulverización y presión de apertura.
    \item Reemplazar juntas y tornillos si es necesario.
    \item Montar con par de apriete: [ ] N·m.
\end{enumerate}

\subsection{Mantenimiento del turbocompresor}
\begin{enumerate}[label=\arabic*.]
    \item Revisar juego axial y radial del eje.
    \item Verificar fugas de aceite en admisión y escape.
    \item Comprobar presión de soplado.
    \item Revisar mangueras y abrazaderas.
    \item Cambiar aceite y filtro con mayor frecuencia si hay polvo.
\end{enumerate}
